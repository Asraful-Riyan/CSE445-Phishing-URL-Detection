PROJECT MODEL DESIGN

Dataset label:
0 = Phishing
1 = Legitimate

Six model comparison:
1. Logistic Regression - supervised
2. SVM - supervised
3. Random Forest - supervised
4. XGBoost - supervised
5. K-Means - unsupervised baseline with cluster-to-class mapping
6. LLM - zero-shot feature-to-text classification

Best model selection for deployment:
Only supervised models 1-4 are candidates for the saved real-time detector.
Selection priority:
1. Highest phishing recall
2. Highest phishing F1
3. Highest ROC-AUC

Why:
Missing a phishing URL (false negative) is more dangerous than incorrectly warning about a legitimate URL.

LLM comparison note:
The LLM can be evaluated on a smaller stratified/test subset because token generation is substantially slower than numerical ML inference. Do not claim the LLM was trained on the tabular dataset; it is a zero-shot comparison unless you later fine-tune it.
